⚠️ 회사 PC 관련 중요 안내 — 반드시 확인해 주세요

회사 노트북/PC에 보안 프로그램(DRM, DLP, 백신 등)이 설치되어 있는 경우, 실습이 불가능할 수 있습니다.
보안 프로그램이 설치된 환경에서는 프로그램 설치 자체가 차단되거나, 설치 후에도 정상 실행되지 않을 수 있습니다.

따라서 개인 노트북을 지참하시는 것을 적극 권장해 드립니다.
부득이하게 회사 PC를 사용해야 하는 경우, 사전에 IT/정보보호 부서에 프로그램 설치 승인을 요청해 주시기 바랍니다.

설치 순서 (중요: 반드시 아래 순서대로 진행)

순서 프로그램 용도 소요시간
1 Git for Windows 터미널 환경(Git Bash), 버전 관리 5분
2 Python 3.12 데이터 분석, AI 자동화 실습 10분
3 Node.js (LTS) AI 도구 실행 환경 5분
4 VS Code 코드 편집기 (실습 메인 화면) 5분
5 Antigravity Google AI 코딩 어시스턴트 10분

1️⃣ Git for Windows 설치

목적: 명령어 입력 창(터미널)을 제공하며, 이후 모든 설치 확인에 사용됩니다.

Step 1. 아래 링크를 클릭하여 다운로드 페이지로 이동합니다.
🔗 https://git-scm.com/download/win

Step 2. 페이지에 접속하면 아래와 같은 화면이 나타납니다. "Click here to download" 라는 링크가 보이는데, 클릭하면 다운로드가 자동으로 시작됩니다.
※ 파일명 예: Git-2.47.1-64-bit.exe

Step 3. 다운로드된 파일을 더블클릭하여 실행합니다. 화면에 Git 설치 마법사 창이 열립니다.

Step 4. [Next] 버튼을 계속 눌러 설치를 진행합니다. 모든 옵션은 기본값 그대로 두시면 됩니다. 중간에 선택 항목이 여러 개 나오지만 모두 기본 설정으로 진행해 주세요.

Step 5. [Install] 버튼을 클릭하면 설치가 진행됩니다. 설치 진행 바가 100%가 되면 [Finish] 버튼을 클릭합니다.

✅ 설치 확인

1. 바탕화면의 빈 공간을 우클릭합니다.
2. 메뉴에서 "Open Git Bash here" 항목이 보이면 설치 성공입니다.
3. Git Bash 창에 git --version을 입력하고 Enter를 누릅니다. git version 2.47.x 라고 출력되면 정상입니다.

2️⃣ Python 3.12 설치 ⭐가장 중요

목적: 교육 데이터 분석, AI 자동화 실습의 핵심 언어입니다.

⚠️ 설치 시 주의사항 (가장 많이 발생하는 오류)
Python 설치 첫 화면에서 하단에 있는 "Add Python 3.12 to PATH" 항목을 반드시 체크해야 합니다. 이 항목에 체크하지 않으면, 이후 모든 실습에서 Python을 인식하지 못해 진행이 불가능합니다.

Step 1. 아래 링크를 클릭하여 다운로드 페이지로 이동합니다.
🔗 https://www.python.org/downloads/

Step 2. 페이지 상단에 노란색 버튼으로 "Download Python 3.12.x" 라고 표시됩니다. 이 버튼을 클릭하면 다운로드가 시작됩니다.
※ 파일명 예: python-3.12.x-amd64.exe

Step 3. 다운로드된 파일을 더블클릭하여 실행합니다.

Step 4. 설치 창이 열리면, 아래쪽에 두 개의 체크박스가 있습니다:

  • ☐ Use admin privileges when installing py.exe — 기본값 유지 (체크된 상태)
  • ☐ Add Python 3.12 to PATH → 반드시 체크하세요 ⭐

Step 5. 두 번째 항목(Add to PATH)에 체크한 후, 상단의 [Install Now] 버튼(하늘색 막대 아이콘)을 클릭합니다.

Step 6. 설치가 진행되는 동안 잠시 기다립니다. 진행 바가 끝나면 "Setup was successful" 이라는 메시지가 나타납니다.

Step 7. 하단의 [Close] 버튼을 클릭하여 창을 닫습니다.

✅ 설치 확인

1. 키보드에서 Windows 로고 키 + R 을 동시에 누릅니다. (왼쪽 아래 깃발 모양 키)
2. 작은 '실행' 창이 열리면 cmd 라고 입력하고 [확인] 또는 Enter 키를 누릅니다.
3. 검은색 배경의 명령 프롬프트 창이 열립니다.
4. python --version 이라고 입력하고 Enter 키를 누릅니다.
5. 다음 줄에 Python 3.12.x 라고 출력되면 설치 완료입니다.

3️⃣ Node.js (LTS) 설치

목적: 일부 AI 도구 및 패키지 실행 환경으로 사용됩니다.

Step 1. 아래 링크를 클릭하여 다운로드 페이지로 이동합니다.
🔗 https://nodejs.org/

Step 2. 페이지 중앙에 두 개의 다운로드 버튼이 있습니다. 왼쪽의 "LTS (Recommended For Most Users)" 버튼(초록색)을 클릭합니다.
※ 오른쪽 "Current" 버튼은 클릭하지 마세요. LTS가 안정화 버전입니다.
※ 파일명 예: node-v22.x.x-x64.msi

Step 3. 다운로드된 파일을 더블클릭하여 실행합니다.

Step 4. [Next] 버튼을 눌러 진행합니다. 라이선스 약관 화면에서 "I accept the terms in the License Agreement" 에 체크하고 [Next]를 클릭합니다.

Step 5. 설치 경로 및 옵션 화면은 모두 기본값 그대로 진행합니다. 중간에 "Tools for Native Modules" 라는 체크박스 화면이 나오면 체크하지 않고 [Next]를 클릭합니다.

Step 6. [Install] 버튼을 클릭합니다. 사용자 계정 컨트롤(UAC) 창이 뜨면 [예]를 클릭합니다. 설치가 완료되면 [Finish]를 클릭합니다.

✅ 설치 확인

1. 명령 프롬프트(cmd)를 엽니다. (Windows키 + R → cmd 입력 → Enter)
2. node --version 을 입력하고 Enter 키를 누릅니다.
3. v22.x.x 라고 출력되면 설치 완료입니다.

4️⃣ VS Code (Visual Studio Code) 설치

목적: 실습 시 사용할 메인 코드 편집기입니다.

Step 1. 아래 링크를 클릭하여 다운로드 페이지로 이동합니다.
🔗 https://code.visualstudio.com/

Step 2. 페이지 상단에 파란색 "Download for Windows" 버튼이 있습니다. 이 버튼을 클릭하여 다운로드합니다.
※ 파일명 예: VSCodeUserSetup-x64-1.9x.x.exe

Step 3. 다운로드된 파일을 더블클릭하여 실행합니다.

Step 4. 라이선스 약관 화면에서 "동의합니다"를 선택하고 [다음]을 클릭합니다.

Step 5. 설치 위치 선택 화면은 기본값 그대로 [다음]을 클릭합니다.

Step 6. 바로가기 만들기 화면에서 "바탕 화면에 바로가기 만들기"에 체크하고 [다음]을 클릭합니다.

Step 7. 추가 작업 선택 화면에서 다음 두 항목에 반드시 체크합니다:

  • ☑ "(탐색기 파일/폴더 우클릭 시) 'Code로 열기' 작업 추가"
  • ☑ "경로에 코드 등록 (다시 시작한 후 적용)"

Step 8. 나머지 항목은 기본값 그대로 두고 [다음] → [설치] 버튼을 클릭합니다. 설치 완료 후 [마침] 버튼을 클릭합니다.

✅ 설치 확인

1. 바탕화면에 파란색 VS Code 아이콘이 생성되었는지 확인합니다.
2. 아이콘을 더블클릭하여 실행합니다. VS Code 창이 정상적으로 열리면 완료입니다.

5️⃣ Antigravity 설치

목적: Google의 AI 코딩 어시스턴트로, 세미나 실습에서 코드 생성 및 자동화를 체험합니다.

📌 사전 준비물: Google (Gmail) 계정이 필요합니다. 계정이 없으신 분은 먼저 계정을 만들어 주세요. (https://accounts.google.com/signup)

Step 1. 아래 링크를 클릭하여 다운로드 페이지로 이동합니다.
🔗 https://antigravity.google

Step 2. 페이지의 "Download" 버튼을 클릭합니다.

Step 3. Google 계정 로그인 화면이 나타나면 본인의 Google (Gmail) 계정으로 로그인합니다.

Step 4. 안내에 따라 다운로드 및 설치를 진행합니다.

Step 5. 설치 완료 후 프로그램을 실행하여 Google 계정이 정상적으로 연동되었는지 확인합니다.

✅ 설치 확인

1. Antigravity를 실행하여 Google 계정 로그인이 완료된 상태를 확인합니다.
2. 메인 화면이 정상적으로 표시되면 완료입니다.

✅ 전체 설치 확인 (한 번에)

모든 설치가 끝났다면, 아래 명령어로 한 번에 확인할 수 있습니다.

  1. 명령 프롬프트(cmd)를 엽니다. (Windows키 + R → cmd → Enter)
  2. 아래 명령어를 한 줄씩 입력하고 Enter를 누릅니다:
git --version
python --version
node --version
code --version

위 4개 명령어 모두 버전 번호가 출력되면 기본 설치가 완료된 것입니다.

⚠️ 설치 시 주의사항

1. 회사 PC 보안 프로그램: 회사 노트북에 보안 프로그램(DRM, DLP, 사내 백신 등)이 설치되어 있는 경우, 설치 및 실습이 차단될 수 있습니다. 가급적 개인 노트북을 지참해 주세요.
2. 설치 순서 준수: 반드시 Git → Python → Node.js → VS Code → Antigravity 순서로 설치해 주세요. 순서가 바뀌면 환경 설정 문제가 발생할 수 있습니다.
3. Python "Add to PATH" 필수 체크: Python 설치 시 이 항목을 체크하지 않으면 실습이 진행되지 않습니다.
4. 관리자 권한 실행: 모든 설치 파일은 우클릭 → "관리자 권한으로 실행"을 권장합니다.
5. 재부팅 권장: 모든 설치가 완료된 후 한 번 재부팅하면 환경 설정(PATH)이 확실히 적용됩니다.
